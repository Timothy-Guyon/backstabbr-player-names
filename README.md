# Backstabbr Player Names

Userscript that shows who plays each country next to every country name on backstabbr.com game pages, with optional nicknames.

Install (Tampermonkey/Violentmonkey on desktop, Userscripts on iOS Safari, Violentmonkey on Android Firefox): open
https://raw.githubusercontent.com/Timothy-Guyon/backstabbr-player-names/main/backstabbr-player-names.user.js
Bump `@version` on every change so installed copies auto-update.
